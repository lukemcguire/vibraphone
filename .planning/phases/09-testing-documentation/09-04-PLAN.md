# Vibraphone

[Badges row]

## The Problem

AI coding agents are fast but unsafe. They skip tests, ignore lint failures, and commit without review. Vibraphone enforces quality gates between code changes and commits - not through prompting, but through tooling.

## The Solution

Vibraphone is an MCP server that provides:

- **Quality Gates**: Tests, lint, format, and LLM-powered code review before any commit
- **Worktree Isolation**: Each task gets its own git worktree for clean branch management
- **Session Recovery**: Agents can resume interrupted work
- **Circuit Breakers**: Automatic escalation when quality gates fail repeatedly

## Installation

```bash
# Install via pip
pip install vibraphone

# Or via uv
uv tool install vibraphone
```
