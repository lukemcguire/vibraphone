<task type="auto">
  <name>Task 2: Create SessionManager class</name>
  <files>src/vibraphone/utils/session.py</files>
  <action>
Add SessionManager class to session.py for persistence operations.

SessionManager methods:
- __init__(self, project_root: Path) — Store session_file path as .vibraphone/session.json
- load(self) -> SessionState | None — Load session from JSON file, return None if not exists
- save(self, state: Session) -> None — Atomically save session (temp file + rename)
- clear(self) -> None — Delete session file if exists

Atomic write pattern (per RESEARCH.md Pattern 3):
1. Create parent directory if needed: session_file.parent.mkdir(parents=True, exist_ok=True)
2. Write to temp file in same directory: tempfile.NamedTemporaryFile(mode="w", dir=parent, delete=False)
3. Write state.model_dump_json() to temp file
4. Close temp file
5. Rename temp file to session file (atomic on POSIX): Path(temp_name).rename(session_file)

Load pattern:
1. Check if session_file.exists()
2. Read file content: session_file.read_text()
3. Parse JSON: json.loads(content)
4. Return SessionState(**data) — Pydantic handles Path and datetime conversion

Handle edge cases:
- Session file doesn't exist → load returns None
- Invalid JSON in session file → let it raise (will be caught at startup)
- Missing parent directory → create it in save()
</action>

  <done>SessionManager with load/save/clear methods working with atomic writes</done>
</task>
