@mcp.tool
async def start_task(task_id: str) -> dict:
    """Start task in isolated git worktree.

    Creates worktree at {worktrees_path}/{repo-name}/{task-id}/
    with branch feat/{task-id} from main.

    Args:
        task_id: Task identifier (from br output, e.g., bd-abc123)

    Returns:
        Dict with worktree_path, branch_name, and next_steps per CONTEXT.md
    """
Implementation:
1. Get config and project root
2. Get repo_name from project_root.name
3. Call create_worktree(task_id, config.worktrees_path, project_root, repo_name)
4. Build branch_name = f"feat/{task_id}"
5. Create SessionState with task_id, worktree_path, branch_name, datetime.now()
6. Save session: SessionManager(project_root).save(state)
7. Return dict with worktree_path, branch_name, and next_steps list

next_steps per CONTEXT.md Tool Result Format:
- "Work in the worktree: cd {worktree_path}"
- "Make changes and commit them"
- "When done, call merge_task to integrate into main"

Handle errors: create_worktree raises WorktreeError, let it propagate (FastMCP handles exceptions)

@mcp.tool
async def merge_task(task_id: str) -> dict:
    """Rebase task branch into main.

    Args:
        task_id: Task identifier

    Returns:
        Dict with success status and next_steps, or error with conflict details
    """
Implementation per RESEARCH.md and CONTEXT.md:
1. Load session: state = SessionManager(project_root).load()
2. If no session or state.task_id != task_id, return error dict:
   - error_type="NoActiveSession"
   - message=f"No active session for task {task_id}"
   - suggested_action="Run start_task first"
3. Call rebase_onto_main(state.worktree_path, state.branch_name)
4. On success, return:
   - success=True
   - branch=branch_name
   - next_steps=["Rebase successful", "Run cleanup_task to remove worktree and delete branch"]
5. On RebaseError, return error.model_dump() (conflicted_files included)

Note: Session is NOT cleared after merge - cleanup_task handles that
</action>

@mcp.tool
async def cleanup_task(task_id: str) -> dict:
    """Remove worktree and delete branch after merge.

    Args:
        task_id: Task identifier

    Returns:
        Dict with success status and next_steps, or error if guards fail
    """
Implementation per CONTEXT.md Cleanup Safety Guards:
1. Load session: state = SessionManager(project_root).load()
2. If no session or state.task_id != task_id, return error dict

3. Safety check - uncommitted changes:
   - changes = await check_uncommitted_changes(state.worktree_path)
   - If changes not empty, return error:
     - error_type="UncommittedChanges"
     - message="Uncommitted changes in worktree. Commit or stash before cleanup."
     - suggested_action=f"Files with changes: {', '.join(changes[:5])}"

4. Safety check - branch merged:
   - If NOT check_branch_merged(state.branch_name, project_root), return error:
     - error_type="BranchNotMerged"
     - message="Task branch not merged. Run merge_task first."
     - suggested_action="Run merge_task to rebase onto main"

5. Remove worktree: await remove_worktree(state.worktree_path, project_root)

6. Delete branch:
   - Run: git branch -d {branch_name}
   - cwd=project_root
   - Ignore if this fails (branch might already be gone)

7. Clear session: SessionManager(project_root).clear()

8. Return:
   - success=True
   - next_steps=["Worktree removed and branch deleted", "Task is complete — mark it complete with complete_task"]
</action>

@mcp.tool
async def recover_session() -> dict:
    """Check for stale session and return state.

    Returns session info if active session exists, or message if none.
    Use this after server startup to resume interrupted work.
    """
Implementation per RESEARCH.md:
1. Load session: state = SessionManager(project_root).load()
2. If no state, return:
   - session=None
   - message="No active session found"

3. Check if worktree exists:
   - If not state.worktree_path.exists(), return:
     - session=None
     - message=f"Stale session for task {state.task_id} — worktree no longer exists"
     - suggested_action="Run cleanup_task to clear session, or start_task to begin fresh"

4. Valid session, return:
   - session={task_id, worktree_path, branch_name, started_at}
   - message=f"Session found for task {state.task_id}"
   - next_steps=["Continue work: cd {worktree_path}", "Or clean up: cleanup_task {task_id}"]

This is a read-only check - no state changes.
</action>

  <done>recover_session MCP tool returns session state or not-found message</done>
