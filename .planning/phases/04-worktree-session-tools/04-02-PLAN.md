Signature:
async def create_worktree(
    task_id: str,
    worktrees_path: Path,
    project_root: Path,
    repo_name: str,
) -> Path

Implementation:
1. Expand tilde in worktrees_path: worktrees_path = worktrees_path.expanduser()
2. Build worktree path: worktrees_path / repo_name / task_id
3. Build branch name: f"feat/{task_id}"
4. Create parent directories: worktree_path.parent.mkdir(parents=True, exist_ok=True)

5. Check if branch already exists (per CONTEXT.md collision handling):
   - Run: git branch --list {branch_name}
   - If stdout not empty, raise WorktreeError with error_type="BranchAlreadyExists"

6. Create worktree with new branch from main:
   - Run: git worktree add -b {branch_name} {worktree_path} main
   - cwd=project_root
   - If returncode != 0, raise WorktreeError with error_type="WorktreeCreationFailed"

7. Return worktree_path

Use asyncio.create_subprocess_exec pattern from cli_runner.py (NOT subprocess.run).
</action>

  <files>src/vibraphone/utils/worktree_ops.py</files>
  <action>
Add rebase_onto_main async function per RESEARCH.md Pattern 2 and CONTEXT.md locked decisions.

Signature:
async def rebase_onto_main(worktree_path: Path, branch_name: str) -> dict

Implementation:
1. Fetch latest main:
   - Run: git fetch origin main
   - cwd=worktree_path
   - Ignore returncode (might be offline)

2. Attempt rebase:
   - Run: git rebase origin/main
   - cwd=worktree_path
   - If returncode == 0, return {"success": True, "branch": branch_name}

3. On conflict (per CONTEXT.md conflict handling):
   a. Get conflicted files: git diff --name-only --diff-filter=U
   b. Parse stdout into list of files
   c. Abort rebase: git rebase --abort (CRITICAL - must run before returning)
   d. Raise RebaseError with:
      - error_type="RebaseConflict"
      - message=f"Rebase conflicts detected in {len(conflicted_files)} file(s)"
      - suggested_action="Resolve conflicts manually, then retry merge_task"
      - conflicted_files=list of files

CRITICAL: Always run git rebase --abort before raising RebaseError to restore clean state.
</action>
