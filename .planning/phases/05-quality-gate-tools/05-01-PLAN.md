Create async command runner for quality gate commands (test, lint, format, check).

Follow the pattern from cli_runner.py but with these differences:
1. Returns (returncode, stdout, stderr) tuple instead of parsed JSON
2. Supports command discovery from config (vibraphone.yaml override -> justfile default)
3. Supports component suffix (e.g., "server" -> "test-server")

Default commands from CONTEXT.md:
```python
DEFAULT_COMMANDS = {
    "test": "just test",
    "lint": "just lint",
    "format": "just format",
    "check": "just check",
}
```

get_command() function:
- Check config.quality_gate.commands.{type} first
- Fall back to DEFAULT_COMMANDS
- Handle component suffix: if command starts with "just " and component provided, append "-{component}"

run_command() async function:
- Use asyncio.create_subprocess_exec (NOT subprocess.run)
- Capture stdout and stderr
- Return tuple[int, str, str] (returncode, stdout, stderr)
- Accept cwd parameter for working directory

Do NOT use CliError from cli_runner.py - this module returns raw output for tools to process.

<task type="auto">
  <name>Task 2: Create circuit_breaker.py with escalation response generation</name>
  <files>src/vibraphone/utils/circuit_breaker.py</files>
  <action>
Create CircuitBreaker class for per-tool failure tracking with escalation.

Per CONTEXT.md locked decisions:
- When tripped: Block the agent entirely, return escalation response
- Counter reset: Reset on success (one passing test clears the counter)
- Thresholds: Configurable per-tool, default 5 for tests, 3 for review
- Scope: Per-tool independent counters (tests, lint, review each have their own)

CircuitBreaker class:
```python
class CircuitBreaker:
    def __init__(self, max_attempts: int | None, tool_name: str):
        self.max_attempts = max_attempts
        self.tool_name = tool_name

    def check(self, current_attempts: int) -> dict | None:
        """Return escalation response if tripped, None otherwise."""

    def is_tripped(self, current_attempts: int) -> bool:
        """Check if circuit breaker threshold exceeded."""

    @staticmethod
    def escalation_response(tool_name: str, attempts: int, max_attempts: int) -> dict:
        """Generate escalation response with human actions."""
```

escalation_response must include:
- status: "ESCALATED"
- error_type: "CircuitBreakerTripped"
- message: "{tool_name} failed {attempts} times (max: {max_attempts})"
- human_actions: ["Reset circuit breaker and let agent continue", "Abandon task and start over", "Provide guidance then reset breaker"]
- next_steps: ["Await human decision"]

max_attempts=None means no circuit breaker for that tool (return None from check).
</action>
  <verify>python -c "from vibraphone.utils.circuit_breaker import CircuitBreaker; cb = CircuitBreaker(5, 'tests'); print(cb.check(3))"</verify>
  <done>CircuitBreaker class exists with check(), is_tripped(), and escalation_response(). When current_attempts >= max_attempts, check() returns escalation dict. When max_attempts is None, check() returns None.</done>
</task>
