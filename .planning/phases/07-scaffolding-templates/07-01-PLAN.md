<task type="auto">
  <name>Task 2: Configure pyproject.toml for template bundling</name>
  <files>
    pyproject.toml
  </files>
  <action>
    Add hatchling build configuration to include templates directory in the wheel.

    Add this section to pyproject.toml after the [build-system] section:

    ```toml
    [tool.hatch.build.targets.wheel]
    # Include templates directory in wheel for importlib.resources access
    artifacts = ["src/vibraphone/templates/"]
    ```

    This ensures templates are bundled when running `pip install .` or `uv tool install .`.

    Reference: RESEARCH.md Pitfall 1 - without this, templates won't be in the wheel.
  </action>
  <verify>
    grep -A3 "\[tool.hatch.build.targets.wheel\]" pyproject.toml
  </verify>
