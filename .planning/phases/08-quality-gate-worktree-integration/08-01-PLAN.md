  <name>Task 1: Create execution context helper module</name>
  <files>src/vibraphone/utils/context.py</files>
  <action>
Create `src/vibraphone/utils/context.py` with two helper functions:

1. `get_execution_context() -> tuple[Path, SessionState | None]`
   - Calls `get_project_root()` to get the project root
   - Creates `SessionManager(project_root)` and calls `load()`
   - If session exists AND `state.worktree_path.exists()`, returns `(state.worktree_path, state)`
   - Otherwise returns `(project_root, None)`
   - This is the key integration point that bridges session state to quality gate execution

2. `get_effective_task_id(session: SessionState | None) -> str`
   - Returns `session.task_id` if session is not None
   - Returns `"default"` otherwise
   - Used by quality gate tools to derive task_id from session when not explicitly provided

Import structure:
```python
from pathlib import Path
from vibraphone.config import get_project_root
from vibraphone.utils.session import SessionManager, SessionState
```

This module intentionally has no side effects - it only provides pure helper functions for resolving execution context.
