The module must include:

1. **Regex patterns:**
   - `_FRONTMATTER_RE`: Matches YAML frontmatter between `---` fences
   - `_TASKS_RE`: Matches `<tasks>...</tasks>` XML blocks
   - `_BARE_AMP_RE`: Matches bare `&` not part of XML entities
   - `_KNOWN_TAGS`: List of structural XML tags (tasks|task|name|files|action|verify|done|title|description|labels|type|blocked_by)
   - `_STRUCTURAL_TAG_RE`: Matches `<` followed by known structural tags

2. **Functions (all pure, no I/O):**
   - `extract_frontmatter(content: str) -> dict`: Extract YAML frontmatter, return {} if not found
   - `sanitize_xml_content(raw: str) -> str`: Escape bare `&` and `<` not part of known XML structure
   - `extract_tasks_from_xml(body: str) -> list[dict]`: Find `<tasks>` block, parse each `<task>` element, return list of task dicts with keys from child elements (title, description, labels, type, blocked_by, etc.)
   - `detect_new_components(body: str) -> bool`: Heuristic check for new service/endpoint/component creation keywords

Use `defusedxml.ElementTree.fromstring` for XML parsing (safe from XXE attacks).

Follow the exact implementation patterns from RESEARCH.md Pattern 1.
