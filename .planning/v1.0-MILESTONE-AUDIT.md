## Integration Gaps

### Critical: Quality Gates Ignore Worktree Context

**Gap ID:** INT-001
**Severity:** Blocker
**Affected Requirements:** QUAL-06
**From:** quality_gate_tools.py (Phase 5)
**To:** session.py (Phase 4)

**Description:**
The quality gate tools (`run_tests`, `run_lint`, `run_format`, `request_code_review`, `attempt_commit`) all use `get_project_root()` to determine where to run commands. They do NOT check for an active worktree session.

**Impact:**
When an agent follows the intended workflow:
1. `start_task` creates worktree at `~/.vibraphone/worktrees/task-id/`
2. Agent works in worktree
3. `run_tests` runs tests in **main repo**, not worktree
4. `request_code_review` stages files in **main repo**
5. `attempt_commit` commits to **main repo**, not worktree

**Expected Behavior:**
```python
# In attempt_commit, run_tests, request_code_review:
session = get_session_manager()
state = session.load()
if state and state.task_id == task_id:
    work_dir = state.worktree_path
else:
    work_dir = get_project_root()
```
